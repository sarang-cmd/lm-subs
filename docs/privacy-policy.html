Privacy Policy

Subtitles for NotebookLM is an open-source, Bring-Your-Own-Key (BYOK) browser extension. We operate zero backend servers, collect zero analytics or telemetry, and never see your NotebookLM notebooks, audio, subtitles, or API keys.

1. Data Stored Locally on Your Device

All configuration — including your chosen Speech-to-Text API keys, provider queue order, caption styling preferences, and up to 35 cached Video Overview subtitle tracks — is stored exclusively in your browser's local chrome.storage.local database on your machine. API keys are read strictly inside the isolated Manifest V3 background Service Worker and are never exposed to web page scripts.

2. How Video Overview Audio Is Processed

When you generate or open a NotebookLM Video Overview (and automatic captioning or manual generation is active), the extension downloads the Video Overview media stream from Google's CDN using your existing browser session, strips the video track locally in JavaScript so only the compact audio track (.m4a or 16 kHz mono .wav) remains, and sends that audio directly from your browser to the Speech-to-Text provider(s) you explicitly configured (such as Groq, Mistral, Google Gemini, Deepgram, AssemblyAI, Gladia, Cloudflare, ElevenLabs, Hugging Face, OpenRouter, OpenAI, or your own localhost server).

3. Third-Party Speech-to-Text Providers

Network requests to any third-party AI/STT provider occur only after you enter an API key (or local URL) and grant Chrome's optional host permission for that specific domain. Audio sent to your chosen provider is governed by that provider's own API terms and data-retention policy.

4. Deleting Your Data

You can delete individual cached subtitle tracks, clear the entire cache, or remove saved API keys at any time from the extension's Settings page, or remove all stored data immediately by uninstalling the extension.

LM Subs project metrics

A public view of the LM Subs repository, with live stars, forks, weekly commits, a contribution calendar, and contributor activity. The page also shows anonymous aggregate website download requests and their country distribution. It does not show private extension usage or anyone's personal statistics.

Public repository activity

  • Repository stars and forks, loaded from the public GitHub API.
  • Commit activity grouped by week and by day for the past year.
  • Contributors recognized by GitHub, with a link to the full contribution graph.

Anonymous download requests

The download chart counts clicks on website download links, not completed file transfers. It shows only aggregate totals by country. The country estimate comes from Vercel, and no IP address or account identifier is stored for these events.

Repository figures update from GitHub and may be temporarily unavailable if its public API is rate limited.

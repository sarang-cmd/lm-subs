04 Installation & Neon Lakebase Deployment

Load unpacked in 30 seconds; connect Neon Postgres with two CLI commands.

STEP A · CHROME EXTENSION

Load Unpacked in Chrome

Download and unzip lm-subs-v0.2.0.zip (or run npm run build), open chrome://extensions, enable Developer mode, and select the extension/ directory. 

npm install
npm run build
# Load ./extension in chrome://extensions
STEP B · NEON AUTH + POSTGRES

Provision Neon Branch

neon.ts declares Neon Managed Auth and Lakebase Postgres. Authenticate once in your browser, deploy resources to production, and apply db/schema.sql. 

neon login
neon deploy --env .env.local
npm run db:migrate
STEP C · SYNC SERVER / VERCEL

Run Locally or Deploy

Start the unified web & Hono sync server locally on port 4173, or deploy straight to Vercel where api/[...route].js connects to DATABASE_URL automatically. 

npm start
# Web + Sync API -> http://localhost:4173

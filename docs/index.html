Engineering & Security

Three-World Manifest V3 Architecture

Designed around strict privilege separation: page-context RPC hooks never touch storage, UI pages never read raw API keys, and full video binaries never leave your browser.

1. Passive batchexecute Hook

page.js observes XMLHttpRequest and fetch responses from /_/LabsTailwindUi/data/batchexecute (R7cb6c create & gArtLc poll) without mutating or delaying NotebookLM's own streams.

2. Pure-JS ISO-BMFF Audio Remuxer

audio-extract.js parses MP4 boxes (moov, trak, stbl), strips the heavy H.264 vide track, and recalculates stco offsets into a valid 4–7 MB .m4a in ~12 ms — without bundling 30 MB of ffmpeg.wasm.

3. Dual Shadow-DOM + PiP Captions

player-overlay.js renders balanced 2-line captions inside a closed ShadowRoot for inline & fullscreen playback while syncing a programmatic VTTCue track for OS Picture-in-Picture.

60-Second Setup

Install Unpacked in Chrome, Brave, Arc, or Edge

No build step required when using the prebuilt release archive.

STEP 01

Download & Unzip

Download notebooklm-subtitles-v0.1.1.zip and extract the notebooklm-subtitles folder.

STEP 02

Load Unpacked

Open chrome://extensions, enable Developer mode, and click Load unpacked on the extracted folder.

STEP 03

Paste Free API Key

Click the toolbar icon and save a free Groq and/or Mistral key.

STEP 04

Open NotebookLM

Generate or open any Studio Video Overview — synchronized subtitles appear automatically.

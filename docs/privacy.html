2. Local-only mode vs optional cloud account

You can use the LM Subs Chrome extension without signing in. In local mode, API keys, captions, and preferences remain inside Chrome local storage (chrome.storage.local), and extracted audio is sent directly from your browser to your selected speech-to-text provider.

3. Account sign-in and granular sync opt-in

When you sign in via Google, GitHub, or a 6-digit email verification code, you choose independently whether to sync AES-256-GCM encrypted API keys, transcriptions, and display preferences. Turning off any category lets you purge stored cloud copies immediately.
